# Disk Usage Treemap GUI

**Disk Usage — Treemap GUI** — визуальный анализатор дискового пространства.
Позволяет сканировать директории, фильтровать файлы по маскам, визуализировать размер поддиректорий в виде Treemap-графа, экспортировать результат и изучать структуру данных с помощью масштабирования и навигации.

---

## 📌 Возможности

### 🗂 Сканирование директорий

* Указание произвольной директории для анализа
* Настраиваемая глубина рекурсивного прохода
* Исключение файлов/папок по маскам (`*.log`, `cache/*`, `*/__pycache__`, и т.п.)
* Фильтрация по расширениям (`.py`, `.jpg`, `.mp4`…)

### 🔍 Анализ файлов и папок

* Подсчёт общего размера
* Поддержка «Top N» крупных элементов
* Расчёт количества блоков по заданному размеру блока
* Определение процента занимаемого места
* Отображение даты изменения (mtime)

### 📊 Treemap-визуализация

* Генерация цветной treemap-карты с помощью `matplotlib` и `squarify`
* Масштабирование колесом мыши
* Перемещение карты (drag)
* Подсказки при наведении: путь, размер и процент
* Возможность сохранения treemap в PNG

### 📄 Удобная таблица

Выводится список всех найденных файлов/папок:
путь → байты → человекочитаемый размер → тип → блоки → процент → дата изменения.

## 📦 Установка

Требуется Python **3.7+**.

Установите зависимости:

```bash
pip install matplotlib squarify
```

> Если `matplotlib` или `squarify` недоступны — интерфейс работает, но treemap отключается.

---

## ▶️ Запуск

```bash
python3 du_gui.py
```

---

## 💡 Использование

### Основные шаги:

1. Нажмите **Browse** и выберите директорию.
2. Укажите фильтры (опционально):

   * *Exclude patterns* — маски исключения (`*.tmp`, `*cache*`)
   * *Include extensions* — только заданные расширения (`.mp4, .mkv`)
3. Настройте:

   * сортировку (size / name / date)
   * глубину (`Depth`)
   * Top N
   * размер блока
4. Нажмите **Scan**.
5. Изучайте таблицу или treemap.
6. При необходимости используйте:

   * фильтр по проценту
   * кнопку **Save Treemap PNG**

## 🔧 Форматы масок

### Исключающие маски:

```
*.log
build/*
*/__pycache__
```

Работают правила `fnmatch`.

### Фильтр по расширениям:

```
.py, .txt, jpg
```

Расширения нормализуются автоматически (добавляется точка, приводится к нижнему регистру).
