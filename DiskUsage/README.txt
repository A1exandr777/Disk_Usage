# Disk Usage Analyzer (CLI)

Этот скрипт — консольная утилита для анализа использования дискового пространства в каталоге.
Она позволяет обходить дерево каталогов, считать размеры файлов/папок и отображать статистику в удобной табличной форме.


## Возможности

* Отображение размера файлов и папок в человеко-читаемом формате (KB, MB, GB).
* Подсветка директорий цветом.
* Гибкая сортировка:
  * `name` — по имени;
  * `size` — по размеру;
  * `depth` — по вложенности;
  * `modify` — по дате модификации;
  * `none` — без сортировки.
* Ограничение глубины обхода подкаталогов.
* Отображение только **N верхних элементов**.
* Режим выделения файлов, которые занимают **N% от общего размера** (`--block`).
* Подсчёт общего размера файлов по расширению.
* Отображение прогресс-бара с процентами.


## Установка

Требуются Python **3.8+** и зависимости:
pip install wcwidth

Также в проекте должен быть модуль `diskUsage.py`, который содержит:

* `sort_dirs` — функция сортировки списка элементов;
* `convert_bytes` — преобразование байт в человеко-читаемый формат;
* `traversal` — обход директорий;
* `get_size` — подсчёт размера директории.

## Использование

### Базовый вызов
python main.py /path/to/dir


### Аргументы

| Аргумент             | Описание                                                    | По умолчанию |
| -------------------- | ----------------------------------------------------------- | ------------ |
| `base_path`          | Путь к начальному каталогу                                  | —            |
| `-s`, `--sort`       | Тип сортировки: `name`, `size`, `depth`, `modify`, `none`   | `none`       |
| `-d`, `--depth`      | Максимальная глубина обхода подкаталогов                    | `100`        |
| `-r`, `--reverse`    | Обратная сортировка                                         | `False`      |
| `-n`, `--noprogress` | Не показывать прогресс                                      | `False`      |
| `-t`, `--top`        | Вывести только N верхних элементов                          | `-1` (все)   |
| `-b`, `--block`      | Вывести файлы, которые занимают N% от общего размера        | `100`        |
| `-e`, `--ext`        | Вывести файлы с указанным расширением и их суммарный размер | `False`      |


### Примеры

Вывести все файлы и папки в каталоге `/home/user`:
python main.py /home/user

Вывести 10 самых больших файлов/папок:
python main.py /home/user -s size -t 10

Показать только файлы, которые занимают 50% от общего размера:
python main.py /home/user -b 50

Посчитать общий размер файлов с расширением `.log`:
python main.py /var/log -e log
